# Student Management System

## Day 2 – MERN Stack Internship Training

A simple Student Management System built using **HTML5**, **CSS3**, and **Vanilla JavaScript**.

This project demonstrates:
- DOM Manipulation
- JavaScript Events
- Form Handling & Validation
- localStorage

---

## Features

### Dashboard
- Total Students
- Average Mark
- Highest Mark
- Lowest Mark

### Add Student
- Name
- Email
- Age
- Department
- Mark
- Automatic Grade calculation

### Student List
- Displays all student details
- Shows calculated Grade
- Delete student option

### Search
- Search students by Name, Email, or Department

### Validation
- Name is required
- Valid email format
- Valid age
- Department is required
- Mark must be between 0–100

### localStorage
- Student data is saved in the browser
- Data remains even after page refresh

---

## Grade Calculation

| Mark Range | Grade |
|------------|-------|
| 90 – 100   | A+    |
| 80 – 89    | A     |
| 70 – 79    | B     |
| 60 – 69    | C     |
| 50 – 59    | D     |
| Below 50   | F     |
